# Roadmap e Próximas Funcionalidades

Este documento lista possíveis evoluções para o projeto `Terminal Radar B3`.

## Melhorias de curto prazo

- Adicionar persistência de carteira no backend (banco de dados ou JSON persistente).
- Implementar autenticação de usuário para contas e carteiras separadas.
- Criar uma API REST completa para operações de carteira.
- Adicionar testes automatizados para backend e frontend.

## Melhorias de médio prazo

- Migrar a interface para um framework front-end moderno (React, Vue ou Svelte).
- Adicionar gráficos interativos com maior detalhamento de histórico.
- Implementar filtros avançados de scanner e alertas por e-mail.
- Permitir importação e exportação de operações em CSV.

## Melhorias de longo prazo

- Criar um deploy em nuvem com Docker e CI/CD.
- Adicionar documentação hospedada via GitHub Pages.
- Integrar com dados de corretoras ou APIs financeiras oficiais.
- Implementar relatórios automáticos de performance e dividendos.

## Prioridades sugeridas

1. Garantir deploy local estável e documentação completa.
2. Adicionar persistência de carteira.
3. Criar testes básicos e CI.
4. Evoluir o scanner com regras adicionais de qualidade.
